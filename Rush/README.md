# Piscine Rush

## English

Three C programs created as short team projects: drawing rectangles with characters, solving a number puzzle, and converting numbers into English text.

Each directory is an independent program with its own input examples and run instructions.

| Project | Behavior |
| --- | --- |
| [Rush 00](Rush00/README.md) | Draw a rectangle of the specified width and height |
| [Rush 01](Rush01/README.md) | Solve a 4-by-4 puzzle constrained by visible building counts |
| [Rush 02](Rush02/README.md) | Convert integers to English using a dictionary |

Build commands and input examples are provided in each program's directory.

## 日本語

短期間のチーム制作で取り組んだ、3つのCプログラムです。文字で図形を描く、数字のパズルを解く、数値を英語に変換するという、それぞれ異なる処理を実装しています。

各ディレクトリは独立したプログラムです。入力方法と実行例は、それぞれのREADMEにあります。

| 課題 | 内容 |
| --- | --- |
| [Rush 00](Rush00/README.md) | 指定した幅と高さの長方形を文字で描く |
| [Rush 01](Rush01/README.md) | 外側から見える数字の数を条件に4×4パズルを解く |
| [Rush 02](Rush02/README.md) | 辞書ファイルを使って整数を英語表記に変換 |

ビルドと入力例は各課題の README に記載しています。
