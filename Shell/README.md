# Piscine Shell

## English

Exercises that combine terminal commands to inspect files and user information. They cover file names, permissions, and archives, with small Shell scripts for searching and transforming command output.

| Directory | Contents |
| --- | --- |
| [Shell00](Shell00/README.md) | Files, archives, Git, and file-type detection rules |
| [Shell01](Shell01/README.md) | Groups, file search, counts, and text processing |

### Example

```sh
cd Shell01
sh ex02/find_sh.sh
```

Searches and counts use the current working directory as their starting point.

## 日本語

端末で使うコマンドを組み合わせ、ファイルやユーザー情報を調べる演習集です。ファイルの名前・権限・圧縮形式を扱い、検索結果やコマンドの出力を加工する小さなShellスクリプトを作っています。

| ディレクトリ | 内容 |
| --- | --- |
| [Shell00](Shell00/README.md) | ファイル・アーカイブ・Git・fileコマンドの判定ルール |
| [Shell01](Shell01/README.md) | グループ、ファイル検索、集計、テキスト処理 |

### 実行例

```sh
cd Shell01
sh ex02/find_sh.sh
```

検索や集計の対象は、スクリプトを実行したときのカレントディレクトリです。
